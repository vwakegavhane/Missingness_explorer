Missingness Matrix

Each row is a distinct missingness pattern; row height is proportional to how many samples share it. Inked cells are missing.

inked = missing value pale = present each row = a pattern (height = share of samples) amber = partly missing (the structured kind)

Variable glyphs

One glyph per variable. The ring fills with the variable's missing rate; amber marks partial (structured) missingness - the interesting kind - while teal marks all-or-nothing columns. The centre dot grows with how many other variables it tends to go missing with. Click a glyph to highlight its column in the matrix.
